## 二、資料是否存好？

**是的，`input_slew` 與 `effective_cap` 已經正確抽出並存到 parquet。**

### parquet 檔的 12 個欄位

| 欄位 | 型別 | 說明 |
|---|---|---|
| `lib_file` | str | 來源 .lib 檔名 |
| `library_name` | str | Liberty 檔內部宣告的 library 名 |
| `corner` | str | Process corner（FF / SS / TT） |
| `cell` | str | 標準單元名稱 |
| `output_pin` | str | 輸出 pin 名 |
| `related_pin` | str | 輸入 pin（timing arc 起點） |
| `timing_sense` | str | negative_unate / positive_unate / non_unate |
| `table_type` | str | cell_rise / cell_fall / rise_transition / fall_transition |
| `template` | str | LUT 範本名（例：delay_template_7x7_x1） |
| **`slew`** | float | **input slew（index_1）** ✅ |
| **`load`** | float | **effective output capacitance（index_2）** ✅ |
| `value` | float | LUT 內的實際值（delay 或 transition） |

### 隨機 5 筆樣本

| cell | corner | table_type | slew (ps) | load (fF) | value |
|---|---|---|---|---|---|
| BUFx3 | TT | rise_transition | 40.0 | 46.08 | 138.87 |
| INVxp33 | TT | cell_fall | 80.0 | 0.72 | 29.69 |
| BUFx2 | SS | fall_transition | 5.0 | 23.04 | 119.53 |
| INVx3 | SS | cell_fall | 160.0 | 92.16 | 212.60 |
| CKINVDCx9p33 | SS | cell_rise | 160.0 | 46.08 | 90.03 |

### 論文用語對照

- `slew` = Liberty 的 `index_1` = **input net transition time**
- `load` = Liberty 的 `index_2` = **total output net capacitance** = **effective cap**
- `value` = LUT 儲存的實際數值（delay 或 transition，依 table_type）

## 三、資料流程（.lib → Tensor）

```
   [ .lib 檔案 ]
        │
        │  liberty-parser 解析（inspect_lib.py 示範這步）
        │
        ▼
   [ Python AST 樹狀結構 ]  ← cell → pin → timing → cell_rise/index_1/index_2/values
        │
        │  iter_cell_samples()  ← 走訪每個節點
        │  攤平成一列 = 一個格點
        │
        ▼
   [ DataFrame (pandas) ]  ← 21,756 筆 × 12 欄位
        │
        │  extract_lib_to_parquet()
        │
        ▼
   [ parquet 檔 ]  ★ 目前的完成點
        │
        │  NldmDataset() 載入 + 過濾 + 正規化
        │
        ▼
   [ PyTorch Tensor batch ]  ← 訓練時餵給 ANN
        │
        ▼
   [   MLP    ] → 預測 delay
```

```
                        ┌────────────────────────┐

    parquet ─────────►  │  │ NldmDataset      │  │ ────►  DataLoader
                        │  │ NormStats        │  │        (batch of tensors)
                        │  └──────────────────┘  │
                        └────────────────────────┘
                                                        │
                                                        ▼
                        ┌────────────────────────┐
                        │  models/mlp_nldm.py    │
                        │  ┌──────────────────┐  │
                        │  │ MLPNldm(nn.Mod)  │  │  ────► 預測值
                        │  └──────────────────┘  │
                        └────────────────────────┘
                                                        │
                                                        ▼
                        ┌────────────────────────┐
                        │  tutorial_train.py     │
                        │  或  train_real.py     │  ←──── 訓練腳本
                        │  （組裝 + 訓練迴圈）    │
                        └────────────────────────┘
```

### 三大模組的職責分離

| 模組 | 職責 | 為什麼要分開 |
|---|---|---|
| `data_loader.py` | 處理資料：從 .lib 抽 → 存 parquet → 包 Dataset | 資料處理是慢的一次性工作，訓練是快的多次工作，分開才不會每次訓練都重跑解析 |
| `models/mlp_nldm.py` | 只定義模型架構 | 之後要換 GNN、Transformer 等，只需改這裡 |
| `train.py` | 組裝訓練迴圈 | 超參數、優化器、Loss 都寫這 |

## 五、ANN 架構詳解

### 5.1 整體形狀（`MLPNldm`）

```
       input                隱藏層 1          隱藏層 2          隱藏層 3          output
    ┌─────────┐          ┌──────────┐      ┌──────────┐      ┌──────────┐      ┌──────┐
    │  slew   │──┐   ┌──►│  neuron  │──┐   │          │      │          │      │      │
    │  (1×)   │  │   │   │  (64 個) │  │   │  (64 個) │      │  (64 個) │      │delay │
    ├─────────┤  ├──►│─  │          │  ├──►│          │──┬──►│          │──┬──►│      │
    │  load   │──┘   │   │  ReLU    │  │   │  ReLU    │  │   │  ReLU    │  │   │  (1×)│
    │  (1×)   │      │   │          │  │   │          │  │   │          │  │   │      │
    └─────────┘      │   └──────────┘  │   └──────────┘  │   └──────────┘  │   └──────┘
      2 features     │       ↑         │       ↑         │       ↑         │      1 output
                     │   Linear(2,64)  │  Linear(64,64)  │  Linear(64,64)  │  Linear(64,1)
                     │   +128 params   │  +4160 params   │  +4160 params   │  +65 params
                     └─────────────────┴─────────────────┴─────────────────┘
                              全連接（每個神經元都連到下一層每個神經元）
                                     總參數量：8,513
```

### 5.2 每一層在做什麼

| 層 | 操作 | 直觀解釋 |
|---|---|---|
| **Linear(2, 64)** | `h₁ = W₁·[slew, load] + b₁` | 把 2 維輸入投射到 64 維「特徵空間」 |
| **ReLU** | `max(0, h₁)` | 引入非線性（沒有這個，多層就只是一個大線性層） |
| **Linear(64, 64)** | `h₂ = W₂·h₁ + b₂` | 特徵重組 + 抽象化 |
| **ReLU** | `max(0, h₂)` | 更多非線性 |
| **Linear(64, 64)** | `h₃ = W₃·h₂ + b₃` | 再一層 |
| **ReLU** | `max(0, h₃)` | 再一層非線性 |
| **Linear(64, 1)** | `y = W₄·h₃ + b₄` | 壓回單一個 delay 預測 |

### 5.3 設計決策的理由

**為什麼是 MLP，不是 CNN/RNN？**
輸入是固定 2 維向量（slew, load），不是影像（用 CNN）也不是序列（用 RNN）。MLP 是預測「純數值 → 數值」關係的標準選擇。

**為什麼隱藏層是 64？**
- 太小（例如 8）→ 學不出複雜非線性
- 太大（例如 512）→ 過擬合、參數浪費
- 64~128 是 NLDM 這種問題的甜蜜點

**為什麼是 3 層隱藏層？**
- 1 層 → 表達能力有限
- 2~4 層 → NLDM 這種平滑函數已足夠
- 更深 → 邊際效益低，梯度也更難訓

**為什麼用 ReLU？**
- 計算快
- 不會像 sigmoid 有梯度消失
- 深度學習的預設選擇

### 5.4 論文可以做的架構實驗

放進論文第 4 章的消融實驗（ablation study）：

1. **改隱藏層寬度**：32 / 64 / 128 / 256
2. **改深度**：2 / 3 / 4 / 5 層
3. **換激活函數**：ReLU / GELU / SiLU
4. **加 Dropout**：0.0 / 0.1 / 0.2
5. **加 BatchNorm / LayerNorm**

`MLPNldm` 這些都用參數控制：
```python
MLPNldm(
    in_features=2,
    hidden_dims=(128, 128, 128, 128),
    dropout=0.1,
    activation=nn.GELU,
)
```

### 5.5 訓練時實際發生的事

```
一個 batch 進來（例如 64 筆）:
    x_batch shape = (64, 2)    ← 64 筆 (slew, load)
    y_batch shape = (64, 1)    ← 64 筆真實 delay

Step 1: 前向傳遞 (forward)
    pred = model(x_batch)      ← shape (64, 1)

Step 2: 算 loss
    loss = MSE(pred, y_batch)  ← 一個純量

Step 3: 反向傳遞 (backward)
    loss.backward()            ← 算出每個權重的梯度

Step 4: 更新權重
    optimizer.step()           ← W ← W - lr × gradient

    重複 → 每個 epoch 跑完全部 batch → 跑 30 個 epoch

訓練結束後:
    model.state_dict() = { W₁, b₁, W₂, b₂, W₃, b₃, W₄, b₄ }
    這 8,513 個數字就是你「學到的 NLDM 函數」
    存成 .pt 檔，之後想用直接載回來預測
```

## 附錄：術語小辭典

| 縮寫 / 名詞 | 全稱 / 意義 |
|---|---|
| NLDM | Non-Linear Delay Model，非線性延遲模型 |
| LUT | Look-Up Table，查表 |
| ANN | Artificial Neural Network，人工神經網路 |
| MLP | Multi-Layer Perceptron，多層感知器（最簡單的 ANN） |
| ReLU | Rectified Linear Unit，最常用的激活函數 |
| PVT | Process, Voltage, Temperature，製程/電壓/溫度三大變異 |
| Corner | 某組 PVT 條件下的特徵化點（如 TT/FF/SS） |
| Slew | 訊號轉態時間（rise/fall time） |
| Effective Cap | 有效輸出負載電容 |
| Cell rise/fall | 輸出從 0→1 / 1→0 的延遲 |
| STA | Static Timing Analysis，靜態時序分析 |
